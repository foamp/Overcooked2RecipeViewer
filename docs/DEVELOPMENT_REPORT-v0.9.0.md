# Overcooked2RecipeViewer v0.9.0 开发与发布检查报告

日期：2026-10-09。正式发布检查：基于本地最新代码重新构建、验证及打包；用户已明确授权提交 main、创建 v0.9.0 标签和正式 Release。代理未执行游戏内测试。

## 完成内容

两处按钮统一为「导出图片 / Export image」。完整预览支持适应窗口、100%、加减按钮、Ctrl+滚轮缩放、横纵滚动，以及放大后的可视区域细节加载。设置区提供透明 / 默认 / 白 / 深色 / 自定义 RGB 背景，紧凑 / 标准 / 宽松图片排版，以及四种外围边距。已移除「当前布局」按钮、设置区底部固定 1x 说明与导出倍率选择；固定为原版卡片 1x，捕获后才显示准确像素尺寸。旧候选版 Layout=Current 自动按 Standard 读取并保存，枚举值不重新编号。

新增「界面设置 / Interface」入口，位于查看器工具栏和预览右上角。支持 50%–200% 连续缩放、百分比输入（如 137%）、厨房绿 / 奶油白 / 深海蓝 / 炭灰四种配色，以及恢复默认；实时生效，在原配置文件的 `[Interface] Scale/Theme` 中记忆，配置管理器隐藏。按钮改为圆角，标题、反馈和操作分区，工具栏随宽度换行。查看器面板、行把手和预览使用统一配色；界面缩放独立于菜谱 Ctrl+滚轮缩放和 PNG 设置。

PNG、复制图片、取消为独立操作。原配置文件中的 `[Image export]` 记忆背景、颜色、排版和边距；导出项通过 `Browsable=false` 隐藏于 BepInEx 配置管理器，快捷键仍显示。旧 `Scale` 键保留兼容，保存时为 1，其旧值不参与渲染。取消、重复打开、加载关卡、插件禁用和退出路径均释放预览与缓存；PNG 分帧写入，取消删除未完成文件。无可见像素或行列表不完整时会报错，避免静默生成缺图。

## 预览与导出一致性

最终化的查看器卡片逐张临时移入离屏 Canvas，两次渲染后恢复父级、同级顺序、位置、比例、旋转和图层，才进入下一帧。双次黑白背景用于恢复直通 RGBA，避免依赖默认 UI 混合结果的 Alpha。完整分辨率卡片缓存到本次会话独有的临时目录。

每卡按全部非零 Alpha 像素裁切，保留 Alpha=1 的浅阴影，并校正裁切后的顶部坐标。紧凑、标准、宽松均保留查看器原有行分组及行内顺序，只以 12/32/64 像素调整卡片间距和行距，按行左对齐，不缩放或裁切。边距为每侧 0/24/64/128 像素，背景覆盖全图。内部 Current 合成分支保留作旧位置算法的回归验证，不再提供 UI 选项。

用户实机反馈指出此前紧凑排版按 1600 像素重新换行，导致手动分行在导出图中失效。本轮移除该逻辑，并在捕获时记录原始行编号；不通过裁切后的 Top 坐标猜测分行。行信息只存于导出缓存，不改变布局存档格式。自动化回归覆盖截图中的 34 张卡片、9 行分组，另有单卡短行、超过 1600 像素宽行与不同透明裁切偏移。

完整预览、可见区域、PNG 和剪贴板共用 `ExportSettings`、`CreatePlan` 与 `ExportScanlines`。背景、排版和边距变化仅重合成，原始缓存位置不改变，也不重新捕获。棋盘格只画在预览 UI 中。透明细节区域与缩略图分区绘制，避免重复混合。输出分辨率与游戏屏幕/查看器缩放相互独立，固定为一输出像素对应一个原版卡片 UI 单位，不把图集像素大小当作整张卡片尺寸，也不承诺新增原素材细节。

界面偏好使用独立 `UiSettings` 模型。IMGUI 使用屏幕适配因子与用户倍率，`RecipeBoard.ApplyInterface` 同步原生 Canvas 的面板预留空间、行把手大小和界面颜色；只刷新滚动边界，不调用重排或修改卡片变换。配色变化原地重绘小型 24×24 圆角纹理；缩放不创建纹理，也不重建原版卡片或导出缓存。设置窗口阻止底层菜谱输入，支持 Esc/Insert 返回、默认重置与退出保存；纹理由现有生命周期统一释放。

## 待实机验收与限制

**没有启动、控制或游玩游戏。** [验收表](TESTING-v0.9.0.md) 覆盖全部要求及生命周期。待验证的主要项目：真实原版卡片离屏渲染、裁切后的阴影/图标完整性、三种分享排版的实机观感、BepInEx 配置界面隐藏效果、固定 1x 尺寸、官方/自制长图、各种分辨率与语言、剪贴板 API/目标软件粘贴、重启后的 UI 设置、关闭/重复打开/场景切换，以及原布局编辑功能回归。新增界面缩放/配色已通过数据与几何检查，字体实际观感、原生 Canvas 与 IMGUI 对齐、滑条输入操作和重启行为需实机验收，不能将这些自动化结果替代实机结果。

安全限制：PNG 最宽 12,000、最高 100,000、最多 2 亿像素；单卡最多 400 万像素且边长不超过 GPU 上限与 8192 的较小值；原始磁盘缓存最多 512 MiB。超过限制会提示并禁用输出，若仅原排列尺寸过大，可切换紧凑排版尝试；固定 1x 仍超出单卡/缓存限制时不能完整导出。初次捕获至少每卡一帧，双次离屏渲染有开销，实际耗时/内存仍需实机测量。

全图预览最长边 2048、最多 200 万像素，放大时再加载可见区域。剪贴板最长边 4096、最多 400 万像素，缩小会明确提示；PNG 不受此缩略上限影响。粘贴透明度由接收软件支持决定，旧应用收到白底兼容格式。低内存/GPU 环境、非常规自制卡片和 UI 生命周期是重点验收风险。进程被强制终止可能遗留本次临时缓存目录。

GUID `io.github.overcooked2.recipepreview`、快捷键键名、配置路径、布局身份/格式/路径、`BepInEx\RecipePreviewExports` 均保留。既有媒体保留；README 标注正式版 v0.9.0，提供 Release 与 ZIP 下载入口。
